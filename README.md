# 14日リコンプ｜習慣ログ

iPhoneで使う、14日間の体重・運動・体調記録PWAです。HTML/CSS/Vanilla JavaScriptだけで動き、記録は利用中のブラウザの `localStorage` に保存します。アカウントや外部APIは使いません。

## ローカルで起動

`index.html` が入ったフォルダでターミナルを開き、Pythonがある場合は次を実行します:

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。HTMLファイルを直接開いても画面は使えますが、Service Workerによるオフライン対応はHTTP/HTTPSでのみ有効です。

## GitHub Pagesで公開

1. この `outputs` フォルダの中身をGitHubリポジトリのルート、または任意のサブフォルダ（例: `docs/`）に配置してコミットします。
2. GitHubのリポジトリで **Settings → Pages** を開き、公開元のブランチと配置先フォルダを選びます。
3. 表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` のURLをiPhoneで開きます。

アプリのリンク、manifest、Service Workerは相対パスで指定しているため、リポジトリ名のサブディレクトリでも動作します。公開後にファイルを更新したときは、Service Workerのキャッシュ名を `sw.js` の `recomp-pwa-v1` から変更すると、更新版へ切り替わりやすくなります。

## iPhoneのホーム画面に追加

1. 公開URLをSafariで開きます（HTTPS接続が必要です）。
2. 共有ボタンを押し、**ホーム画面に追加**を選びます。
3. 表示名を確認して追加します。以後はホーム画面のアイコンから起動できます。

## 使い方と記録

- 起動時に端末の日付を使って今日のToDoを表示します。前後の日へ移動して、過去のチェックと記録も編集できます。
- 準備期間は10/29〜10/30、熊本旅行は10/31〜11/2、本番は11/3〜11/16、振り返りは11/17です。旅行日は運動達成率の対象外です。
- チェック、体重、腹囲、睡眠・疲労・空腹感は入力のたびに自動保存します。ブラウザのデータを消去すると記録も消えるため、記録ページからCSVを定期的に保存してください。
- CSV読み込みは日付単位で取り込み、同じ日付は更新、それ以外は保持します。インポート前に現在データをCSVへ保存しておくと安全です。
- 運動達成率は14日間に計画された個別の運動項目のうち完了した割合です。筋トレ実施回数は、その日の筋トレ項目をすべて完了した日数です。
- 週平均は記録済みの体重だけで算出します。栄養目安は参考値で、警告や食事の自動推定はありません。

## ファイル

- `index.html` — 画面、スタイル、アプリの動作
- `manifest.json` — PWA設定
- `sw.js` — オフライン用キャッシュ
- `icon.svg` — アプリアイコン
- `icon-180.png` — iPhoneホーム画面用アイコン
